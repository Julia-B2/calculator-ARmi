# Калькулятор проектных показателей АР

Инструмент автоматического пересчёта проектных показателей по трём блокам с формированием единого итогового документа.

## Запуск

Калькулятор — статичный сайт без сборки.

**Вариант 1 (просто):** открыть `app/index.html` двойным кликом. Нормативная база встроена в HTML, всё работает оффлайн.

**Вариант 2 (с внешней базой):** запустить локальный HTTP-сервер из папки `app` и открыть страницу в браузере — тогда нормы читаются из `app/data/norms.json`.

```
cd app
npx http-server -p 8777
# открыть http://localhost:8777
```

## Возможности

- Расчёт всех четырёх блоков (машиноместа, лифты, ТКО, социальное обеспечение).
- Машиноместа: два метода расчёта постоянных мест (прил. 5, п. 2 — АГР/АСП по квартирографии; п. 1 — по площади квартир), округление итога в большую сторону, допустимые отклонения ±10 % (п. 6.2.4.1) и ±30 % для приобъектной парковки (п. 6.2.4.3), места постоянного размещения для инвалидов (п. 6.2.3.7).
- Приобъектные машиноместа — по приложению 6 (X / X2 × К1 × К2) с X2 по приложению 1 и К1 по пешевой доступности рельсового каркаса; для регионов без региональных X2 — федеральный ориентир СП 42.13330.2026 (прил. И).
- Лифты: минимальное число по таблице В.1 СП 54.13330.2022, режим «расчёт по ГОСТ Р 52941» с проверкой не менее таблицы В.1, проверка площадей квартир по таблице 5.1 (п. 5.2) и формирование текста обоснования для пояснительной записки.
- Соцобеспечение: расчётное население от СПП жилой части по площади на 1 жителя (тип застройки МКД / ИЖД / блокированная / ВГК — 50 / 56 / 67 / 80 м²), зоны 1–3 с нормами ДОУ и школ и местами ОВЗ, раздельные нормы площади здания и участка, нормативы поликлиник из регионального акта в области здравоохранения.
- Чекбоксы «Функции объекта» в «Исходных данных» (жильё, торговля, школа, поликлиника, офис) управляют показом площадей и составом объектного расчёта.
- Чекбоксы «Включить в итог» для дополнительных составляющих машиномест.
- У каждой строки расчёта — ссылка на пункт нормативного документа.
- Экспорт единого итогового документа (HTML) и выгрузка в XLSX (при отсутствии библиотеки — CSV).
- Печать через `Ctrl+P` (отдельный стиль печати).

## Структура

```
app/
├── index.html          # страница: табы + встроенная копия норм (генерируется)
├── css/                # base.css, print.css
├── data/norms.json     # нормативная база (единый источник правды)
├── js/
│   ├── main.js         # UI и связка с движком
│   ├── utils.js        # форматирование, округление
│   ├── engine.js       # каркас результата
│   ├── blocks/         # parking.js, elevators.js, tko.js, social.js — чистые расчёты
│   └── export/         # htmlDoc.js, word.js, xlsx.js, csv.js
└── assets/             # локальные библиотеки (xlsx.min.js — опционально)
python/
└── parking_calc.py     # второй движок расчёта ММ по той же нормативной базе
tools/
└── build-embedded-norms.mjs   # синхронизация встроенной копии норм в index.html
```

## Важно

- XLSX-экспорт работает из коробки: SheetJS (`xlsx.min.js`, версия 0.20.3) включён в `app/assets/`. При удалении библиотеки экспорт автоматически уходит в CSV.
- Все нормативы и коэффициенты правятся в `app/data/norms.json` — это единственный источник правды.
- Встроенная копия норм внутри `app/index.html` **генерируется автоматически** — не редактируйте её вручную. После правки `app/data/norms.json` выполните:

```
node tools/build-embedded-norms.mjs          # обновить встроенную копию
node tools/build-embedded-norms.mjs --check  # только проверить актуальность
```

- `python/parking_calc.py` — независимый второй движок расчёта машиномест, читающий ту же `app/data/norms.json`; контрольные примеры JS и Python дают совпадающие значения.
