# Калькулятор проектных показателей АР

Инструмент автоматического пересчёта проектных показателей по трём блокам с формированием единого итогового документа.

## Блоки

| Блок | Нормативная база |
|---|---|
| **Машиноместа** | Постановление Правительства Москвы от 23.12.2015 № 945-ПП (в редакции проекта постановления 2026 г.), Приложение 5, п. 1.2; приобъектные (БКТ) — РНГП/МНГП региона, СП 113.13330.2023, СП 42.13330.2016 (ред. от 09.06.2022); МГН — 181-ФЗ ст. 15, СП 59.13330.2020 |
| **ТКО (ТБО)** | СанПиН 2.1.3684-21; СП 42.13330.2016 |
| **Социальное обеспечение** | ПП Москвы № 2152-ПП (табл. 1.4.1, население); ПП Москвы № 2151-ПП в редакции № 921-ПП от 28.04.2025 (образование); СП 158.13330.2014 (поликлиники) |

## Запуск

Калькулятор — статичный сайт без сборки.

**Вариант 1 (просто):** открыть `app/index.html` двойным кликом. Нормативная база встроена в HTML, всё работает оффлайн.

**Вариант 2 (с внешней базой):** запустить локальный HTTP-сервер из папки `app` и открыть страницу в браузере — тогда нормы читаются из `app/data/norms.json`.

```
cd app
npx http-server -p 8777
# открыть http://localhost:8777
```

## Возможности

- Расчёт всех трёх блоков.
- Машиноместа: жилые (945-ПП) + приобъектные (БКТ) с коэффициентами K_i из РНГП/МНГП региона и сценариями использования (max); приобъектные учитываются для всех типов объектов, включая жилой (встроенная коммерция); квоты МГН по 181-ФЗ и шкала специализированных мест по СП 59.13330.2020.
- Чекбоксы «Функции объекта» в «Исходных данных» (жильё, торговля, школа, поликлиника, офис) управляют показом площадей и составом объектного расчёта.
- Чекбоксы «Включить в итог» для дополнительных составляющих машиномест.
- Выбор метода расчёта населения и зоны города в блоке соцобеспечения.
- У каждой строки расчёта — ссылка на пункт нормативного документа.
- Экспорт единого итогового документа (HTML) и выгрузка в XLSX (при отсутствии библиотеки — CSV).
- Печать через `Ctrl+P` (отдельный стиль печати).

## Структура

```
app/
├── index.html          # страница: 4 таба + встроенная копия норм
├── css/                # base.css, print.css
├── data/norms.json     # нормативная база (единый источник правды)
├── js/
│   ├── main.js         # UI и связка с движком
│   ├── utils.js        # форматирование, округление
│   ├── engine.js       # каркас результата
│   ├── blocks/         # parking.js, tko.js, social.js — чистые расчёты
│   └── export/         # htmlDoc.js, xlsx.js
└── assets/             # локальные библиотеки (xlsx.min.js — опционально)
```

Полное ТЗ — в `docs/AGENT-SPEC-CALC.md`.

## Важно

- XLSX-экспорт работает из коробки: SheetJS (`xlsx.min.js`, версия 0.20.3) включён в `app/assets/`. При удалении библиотеки экспорт автоматически уходит в CSV.
- Все нормативы и коэффициенты правятся в `data/norms.json`. Для оффлайн-режима (двойной клик по `index.html`) есть встроенная копия норм внутри `index.html` — при изменении `norms.json` синхронизируйте её при необходимости.
