Функции объекта

Отметьте функции, входящие в объект: показываются только их площади. В объектном расчёте (ТЦ, офис, школа, поликлиника, МФН) площади выбранных функций учитываются автоматически. Для встроенной коммерции в жилом доме используйте блок «Приобъектные (коммерция)».

Площади, вместимость и население

Проверки: Σ площадей по назначению ≤ общей площади; плотность населения — МКД 20–60 м²/чел., офисы 6–15 м²/раб.место. В расчёт машино-мест подставляются площади выбранных функций (торговая → GLA, учебная → школа, медицинская → поликлиника, офисная → офис).

Жилая часть — квартирография

Метод АГР/АСП (прил. 5, п. 2): Nп = A×N1 + B×N2 + C×N3, где A = 0,8, B = 1,2, C = 1,6; N3 — квартиры свыше 100 м², индивидуальные жилые дома и блокированная застройка. Метод градостроительного проектирования (прил. 5, п. 1): Nп = S / (S1 × 2,1) × D. Итог округляется в большую сторону. Для ТЦ/офиса/МФН заполните параметры ниже.

Параметры объекта (класс жилья / ТЦ / офис)

Площади берутся из блока «Площади, вместимость и население». Заполняется для типов «ТЦ», «Офис», «МФН». Коэффициенты K подставляются из норм выбранного региона/уровня (СП 42, прил. Ж).

Приобъектные (коммерция)

Расчёт по приложению 6 ПП № 945-ПП: Nв = X / X2 × К1 × К2, где X2 — расчётный показатель на одно место по виду разрешённого использования (приложение 1), К1 — коэффициент пешей доступности рельсового каркаса, К2 — коэффициент деловой активности (приложение 3). Для регионов, где X2 региональным нормативом не установлен, применяется федеральный ориентир СП 42.13330.2026 (приложение И): N = S / 100 × K. Итог округляется в большую сторону (примечание 3 к приложению 6). При нескольких сценариях в итог берётся максимум.
