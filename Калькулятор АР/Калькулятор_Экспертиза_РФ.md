# Калькулятор для экспертизы (все регионы РФ)

## Теги
#проектирование #экспертиза #нормативы #калькулятор

## Суть решения
Калькулятор на 5 вкладок. Регион и исходные данные вводятся **один раз** на вкладке «Исходные данные» и подтягиваются во все остальные вкладки. На вкладке «Итог» — две кнопки: **Экспорт в Excel** (CSV) и **Экспорт в Word** (готовый текст раздела для пояснительной записки).

---

## Вкладка 1: Исходные данные (единый источник правды)

Все остальные вкладки берут отсюда регион, тип объекта, площади, численность и стадию. Для экспертизы это критично: эксперт видит, что цифры везде согласованы.

| Поле | Тип | Единицы | Валидация | Норматив/обоснование |
| --- | --- | --- | --- | --- |
| Наименование объекта | текст | — | обязательно | из задания на проектирование |
| Адрес / Регион | справочник (все субъекты РФ) | — | обязательно | определяет региональные нормативы |
| Тип объекта | справочник | — | обязательно | определяет применяемые СП/РНГП |
| Стадия проектирования | выбор (ПП / ПД) | — | обязательно | влияет на точность расчёта и формулировки |
| Общая площадь | число | м² | >0, ≤ 500 000 | из ТЭПов/экспликации |
| Жилая/торговая/учебная площадь | число | м² | сумма ≤ общей, >0 | по экспликации помещений |
| Вместимость/количество мест | число | ед. | >0 | из задания |
| Коэффициент загрузки | % или доля (0–1) | — | 0.5–1.2 | по заданию или типовым значениям |
| Количество жителей/сотрудников/посетителей | число | чел. | валидация по плотности | обоснование: «принято по заданию/по СП» |

### Валидации для экспертизы
- **Проверка реалистичной плотности:** МКД — 20–60 м²/чел; офисы — 6–15 м² на рабочее место. Если выходит за пределы — предупреждение: *«Плотность заселения/загрузки не соответствует типовым значениям. Требуется обоснование в ПД»*.
- **Контроль согласованности:** сумма площадей по назначению ≤ общей площади.
- **Региональная проверка:** если региональный норматив ниже федерального минимума (Приказ Минстроя № 250/пр) — система выдаёт предупреждение и применяет федеральное значение.
### Кнопка: Проверить на актуальность норм

- **Действие:** автоматическая проверка всех используемых нормативов по актуальным реестрам. «При нажатии кнопки “Проверить на актуальность норм” (Красного цвета) менять текст на “Проверяю нормы…”, показывать встроенный спиннер справа от текста, блокировать кнопку. 
- **Результат:** если нормы актуальны — ставить статус “Проверено —  [дата]” (зелёный), если есть изменения — “Требуется актуализация” (красный) с кнопкой “Показать список изменений”. Статус сохраняется и отображается рядом с кнопкой до следующего запуска.»
- **Журнал проверки:** дата, пользователь, список актов и статусов (выгружается в CSV).
- **Предупреждения:** если акт отменён/изменён — вывод реквизитов замены и рекомендация пересчёта. 
- **Для экспертизы:** журнал проверки прикладывается к обоснованию как подтверждение актуальности базы. Указать в конечном выгружаемом отчете.

## Вкладки 2–5: Машиноместа, Лифты, Соцобеспечение, ТКО

Во всех этих вкладках **нет повторного ввода региона и основных исходных данных** — они подтягиваются из вкладки 1. Пользователь вводит только специфичные параметры.

### Машиноместа
**Формула:** $N_{мм} = N_{норм} \times Q \times K_{корр}$  
**Источники норм:** ПП‑945 (Москва), РНГП (регионы), Приказ Минстроя № 250/пр (федеральный минимум).  
**Вывод для экспертизы:** таблица расчёта + текстовое обоснование с реквизитами акта.

### Лифты
**Логика:** расчёт по этажности, площади/вместимости и пассажиропотоку.  
**Нормативы:** СП 54.13330.2022 (МКД), СП 118.13330 (общественные здания), ГОСТ 34758‑2021.  
**Поля:** этажность, назначение, пассажиропоток, грузоподъёмность, скорость, минимальное количество по СП, принятое количество.

### Социальное обеспечение
**Формула:** $N_{соц} = P \times n$  
**Источник:** РНГП субъекта РФ.  
**Поля:** численность, норматив, требуемое количество мест, существующая обеспеченность, дефицит/избыток, вывод по обеспеченности.

### ТКО
**Формулы:** $V_{год} = N \times Q$; $M_{год} = V_{год} \times \rho$  
**Источники:** ФЗ № 89‑ФЗ, постановления Правительства РФ, региональные акты об утверждении нормативов накопления ТКО.  
**Поля:** регион (подтянут из вкладки 1), тип объекта, расчётная величина, норматив накопления, плотность отходов, сезонный коэффициент (если есть), объём и масса ТКО, разбивка по фракциям.

## Проверка расчётов и защита от ошибок

1. **Единая база исходных данных:** все вкладки используют данные из вкладки 1 — это исключает расхождения.
2. **Автоматическая подстановка нормативов:** при выборе региона система подтягивает актуальные РНГП, ПП и приказы.
3. **Контроль федерального минимума:** если региональный норматив ниже федерального (по Приказу Минстроя № 250/пр), система выдаёт предупреждение и применяет федеральное значение.
4. **Валидация реалистичности:** проверка плотности, соотношений площадей и численности.
5. **Ссылки на нормативы:** в каждом расчёте явно указаны реквизиты актов (название, номер, дата, пункт).
6. **Допущения:** отдельный блок с описанием, какие коэффициенты применены и почему.
