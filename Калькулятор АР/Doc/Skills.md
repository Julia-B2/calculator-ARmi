# Техническое задание: Калькулятор проектных показателей АР

## 1. Цель проекта

Одностраничный статичный калькулятор (сайт) для автоматического пересчёта проектных показателей по трём блокам и формирования единого итогового документа:

1. **Машиноместа** — по Постановлению Правительства Москвы от 23.12.2015 № 945-ПП (в редакции проекта постановления «О внесении изменений в постановление Правительства Москвы от 23 декабря 2015 г. № 945-ПП», 2026 г.).
2. **ТКО (ТБО)** — по СанПиН 2.1.3684-21 и СП 42.13330.2016.
3. **Социальное обеспечение** — по ПП Москвы № 2152-ПП, ПП Москвы № 2151-ПП, СП 42.13330.2016, СП 158.13330.2014.

Каждый расчётный показатель обязан иметь привязку к конкретному пункту нормативного документа (`refPoint`). Итог — единый документ, формируемый автоматически.

**Принципы:** максимальная простота, минимум зависимостей, работа оффлайн (открывается двойным кликом), прозрачность расчёта.

## 2. Технологический стек (обязательный)

- HTML5 + CSS3 + чистый JavaScript (ES6 modules, `type="module"`).
- Без сборщика, без TypeScript, без бэкенда, без `node_modules`.
- Реактивность — только ванильный JS.
- Стили — чистый CSS (`css/base.css`, `css/print.css`), без внешних фреймворков.
- Экспорт XLSX — SheetJS, подключается **локально** из `assets/`. При отсутствии файла — сработает резервный экспорт CSV.
- Экспорт итогового документа — генерация автономного HTML-файла средствами JS (без библиотек).
- Все нормативы/коэффициенты/ссылки — только в `data/norms.json`.  Сверить текст в авторитетных базах (например https://normativ.kontur.ru/document?documentId=437012&moduleId=9&ysclid=mviefcbe3o969021112 или https://docs.cntd.ru/document/351139048?ysclid=mviefqkn3p308326269, https://www.mos.ru/) — там удобно отслеживать статус документа и видеть все внесённые изменения.

## 4. Блок 1. Машиноместа (945-ПП)

### 4.1 Исходные данные

| Поле | Тип | Ед. | Примечание |
|---|---|---|---|
| Наименование объекта | текст | — | Свободный ввод |
| Количество квартир, всего | число | шт. | Для сверки |
| Квартиры до 70 м² (F1) | число | шт. | Группа 1 |
| Квартиры 70–100 м² (F2) | число | шт. | Группа 2 |
| Квартиры свыше 100 м² (F3) | число | шт. | Группа 3 |

Сумма F1+F2+F3 автоматически сверяется с общим количеством квартир; при расхождении — предупреждение.

### 4.2 Постоянные машино-места

Формула (Приложение 5, п. 1.2):

```
Nп = F1 × 0,8 + F2 × 1,2 + F3 × 1,6
```

По каждой группе выводится строка: `Группа | Кол-во квартир | Коэффициент | Машино-места`.
Итог постоянных — `∑ (F × коэффициент)`, округление до целого.

### 4.3 Дополнительные составляющие

Таблица с чекбоксом «Включить в итог» в каждой строке. Итоговая потребность считается только по включённым строкам.

| id          | Название                      | Способ      | Округление   | По умолчанию |
| ----------- | ----------------------------- | ----------- | ------------ | ------------ |
| guest       | Гостевые ММ                   | 10 % от Nп  | вверх (ceil) | выкл.        |
| mgn_total   | Места для МГН, всего          | 10 % от Nп  | вверх (ceil) | выкл.        |
| mgn_special | Специализированные ММ для МГН | ручной ввод | —            | выкл.        |


Возможность добавлять произвольные строки (название + значение + включение в итог).

### 4.4 Итоговая потребность

`Nитог = Nп + ∑ (включённые доп. составляющие) + Приобъектные ММ (БКТ)`

Выводится формула в текстовом виде, значение, и список включённых компонентов.

### 4.5 Приобъектные машино-места (БКТ) — РНГП/МНГП региона

Основание: СП 113.13330.2023 «Стоянки автомобилей»; СП 42.13330.2016 (ред. от 09.06.2022); РНГП/МНГП региона (региональные/местные нормативы градостроительного проектирования). **Коэффициент K_i (мест на расчётную единицу) задаёт РНГП/МНГП региона — федеральные своды эту цифру не устанавливают.** Утверждается субъектом РФ и муниципалитетом, применяется в части, не противоречащей техрегламентам.

Исходные данные (по заданию на проектирование):

| Параметр | Обозн. | Источник |
|---|---|---|
| Расчётные единицы (м² общей площади / работающих / посетителей в смену / койки / квартиры) | E_i | задание на проектирование |
| Нормативный коэффициент по функции объекта (мест на расчётную единицу) | K_i | РНГП/МНГП региона |
| Понижающие/повышающие коэффициенты (истор. центр, близость метро и т.п.) | f | РНГП/МНГП (обычно 0–20 %) |

Расчёт:

```
# Шаг 1. Базовое число мест (по каждому сценарию использования)
N_баз = Σ_i (K_i × E_i / делитель единицы) × f
# Для площади: N = S / 100 × K (K — мест на 100 м²)
# При нескольких сценариях (БКТ и т.п.) берётся max по сценариям

# Шаг 2. Округление (всегда вверх; минимум 1 при наличии потребности)
N_общ = max(1, ⌈N_баз⌉)
```

В интерфейсе: список функций объекта (торговля, офисы, общепит, бытовое обслуживание, гостиница) с полями K_i и E_i, переключатель единицы, поле коэффициента f, кнопка «Добавить сценарий». Итог по сценариям — максимум.

### 4.6 Места для МГН (181-ФЗ, СП 59.13330.2020)

Основание: Федеральный закон № 181-ФЗ «О социальной защите инвалидов», ст. 15 (ред. от 29.12.2025); СП 59.13330.2020 «Доступность зданий и сооружений для МГН».

Два уровня, показываются раздельно:

```
# Уровень 1 — квота по закону (не менее 10 %, но не менее одного)
N_МГН = max(1, ⌈0,10 × N_общ⌉)

# Уровень 2 — специализированные места (6,0 × 3,6 м), СП 59.13330.2020, п. 5.2.1
N ≤ 100   → max(1, ⌈0,05 × N⌉)
101–200   → 5 + ⌈0,03 × (N − 100)⌉
201–500   → 8 + ⌈0,02 × (N − 200)⌉
N ≥ 501   → 14 + ⌈0,01 × (N − 500)⌉
```

Дополнительно (по запросу):
- Специализированные ММ для гостевых (жильцы) — 10 % от гостевых ММ;
- Специализированные ММ для приобъектных (коммерция) — 10 % от приобъектных ММ.

Габариты мест (для расстановки):
- обычное — минимум 5,3 × 2,5 м (прил. А к СП 113.13330.2023);
- специализированное для инвалида на кресле-коляске — 6,0 × 3,6 м; вдоль проезжей части длина 6,8 м (СП 59.13330.2020, п. 5.2.4; СП 113.13330.2023, п. 5.6).
- Ориентир площади (прикидка): обычное ≈ 13,25 м², МГН ≈ 21,6 м²; с проездами на открытых стоянках обычно 25–30 м²/место.

**Контрольный пример:** помещение 500 м², K = 1 место на 100 м², f = 1 → N = 5 мест; квота МГН = 1; специализированных = 1 (совпадает).

| Норматив накопления ТКО | n | м³/м²·год | 0,1 (региональный) |
| Период вывоза ТКО | T | сут | 3 |
| Габариты контейнера: длина | — | мм | 1377 |
| Габариты контейнера: ширина | — | мм | 1077 |
| Габариты контейнера: высота | — | мм | 1369 |
| Объём контейнера | Vконт | м³ | 1,1 |
| Коэфф. неравномерности накопления | Kн | — | 1,25 |
| Коэфф. заполнения контейнера | Kз | — | 0,75 |
| Количество контейнерных помещений | nпом | шт | 3 |
| Зазор между контейнерами | — | м | 0,35 |
| Отступ от стен | — | м | 1,0 |
| Коэфф. проходов | Kпр | — | 1,2 |

### 5.2 Расчёт (цепочка)

```
Vгод    = Sкв × n                              [м³/год]
Vсут    = Vгод / 365                           [м³/сут]
Vнакопл = Vсут × T × Kн                        [м³]
Vпол    = Vконт × Kз                           [м³]
Nконт   = ceil(Vнакопл / Vпол)                 [шт]
Sосн    = (длина × ширина) / 1e6               [м²]
S1      = ((длина + зазор) × (ширина + зазор)) / 1e6   [м²]
Sобщ    = Nконт × S1                           [м²]
Sпом    = (Sобщ / nпом) × Kпр                  [м²]
Sсум    = Sпом × nпом                          [м²]
```

Нормативные ссылки: СанПиН 2.1.3684-21 (п. 3, п. 11), СП 42.13330.2016 (п. 7.1, п. 7.5).

**Важно:** в исходном образце коэффициенты семейности ошибочно приписаны 2152-ПП — там их нет. Нормативы ДОУ/школ — из 2151-ПП в ред. 921-ПП (зона 1), а не из СП 42.13330 (53/124 относятся к зоне 2).

### 6.2 Исходные данные

Общие:
- Метод расчёта населения: **по площади квартир** или **по типам квартир × коэффициент семейности** (переключатель).
- Зона города: **зона 1** (ДОУ 44 / школы 90) или **зона 2** (ДОУ 63 / школы 124) — выпадающий список.

Метод «по площади»: общая площадь квартир (м²), площадь на человека (33 м²/чел.).

Метод «по типам квартир»: количества по типам (студии, 1–4-комнатные) + коэффициенты семейности (чел./квартиру, редактируемые в интерфейсе; значения по умолчанию — рабочие, подлежат уточнению).

Поликлиники: удельные показатели посещений (5,8 / 13,2 / 19) и площадь на посещение (27 м²).

### 6.3 Расчёт

```
# Население
N (по площади) = ceil( Sкв / 33 )
N (по типам)   = Σ (кол-во квартир типа × коэффициент семейности)

# Образование (по зоне)
ДОУ    = ceil( N / 1000 × douPer1000 )               [мест]
Школы  = ceil( N / 1000 × schoolPer1000 )            [мест]
Sуч.ДОУ   = ДОУ   × уд.площадь по типоразмеру        [м²]
Sуч.школы = Школы × уд.площадь по типоразмеру        [м²]

# Поликлиники
Пос.дет.  = ceil( N / 1000 × 5,8 )                   [пос./см.]
Пос.взр.  = ceil( N / 1000 × 13,2 )
Пос.смеш. = ceil( N / 1000 × 19 )
Площадь i = Пос.i × 27                               [м²]
```

При потребности ниже минимального типоразмера выводится рекомендация по выкупу мощностей или взносу по КРТ.

### 6.4 Проверка на образце (зона 1, метод по площади)

- ДОУ = 1461 × 44/1000 = 64,3 → **65** ✔
- Школы = 1461 × 90/1000 = 131,5 → **132** ✔
- Поликлиники: 9 / 20 / 28 пос./см.; площадь 1539 м² ✔

2. **XLSX** — листы по блокам + сводный лист. Локальный SheetJS; при отсутствии библиотеки — CSV.
