# Калькулятор для экспертизы (все регионы РФ)
это расчётный инструмент для проектировщиков, предназначенный для формирования обосновывающих расчётов, которые можно приложить к проектной документации (ПД) и представить на экспертизу. Он позволяет быстро получить согласованные между собой показатели по ключевым разделам и автоматически сформировать выгрузку в Excel (для таблиц) и Word (для текстовой части пояснительной записки).

## Вкладка 1: Исходные данные (единый источник правды)

Все остальные вкладки берут отсюда регион, тип объекта, площади и численность. Для экспертизы это критично: эксперт видит, что цифры везде согласованы.

**Показатель «Стадия проектирования» удалён** — расчёт ведётся по фактическим исходным данным, стадия в обоснованиях и выгрузках не указывается.

### Валидации для экспертизы
- **Проверка реалистичной плотности:** МКД — 20–60 м²/чел; офисы — 6–15 м² на рабочее место. Вне пределов — предупреждение: *«Плотность заселения/загрузки не соответствует типовым значениям. Требуется обоснование в ПД»*.
- **Контроль согласованности:** сумма площадей по назначению ≤ общей площади.
- **Региональная проверка:** если региональный норматив ниже федерального минимума (Приказ Минстроя № 250/пр) — система выдаёт предупреждение и применяет федеральное значение.

### Кнопка: Проверить на актуальность норм

- **Действие:** автоматическая проверка всех используемых нормативов по реестру `legalActs` в нормативной базе. «При нажатии кнопки “Проверить на актуальность норм” (красного цвета) менять текст на “Проверяю нормы…”, показывать встроенный спиннер справа от текста, блокировать кнопку».
- **Результат:** если нормы актуальны — статус «Проверено — [дата]» (зелёный), если есть изменения — «Требуется актуализация» (красный) со списком изменений. Статус сохраняется и отображается рядом с кнопкой до следующего запуска.
- **Журнал проверки:** дата, пользователь, список актов и статусов (выгружается в CSV).
- **Предупреждения:** если акт отменён/изменён — вывод реквизитов замены и рекомендация пересчёта.
- **Для экспертизы:** журнал проверки прикладывается к обоснованию как подтверждение актуальности базы; включается в выгружаемые документы (HTML, Word).

## Вкладка 2: Машиноместа

Общая схема расчёта: `N_мм = N_норм × Q × K_корр`, где K_корр — коэффициент корректировки из задания. Ниже — составные части.

### 2.1 Постоянные машиноместа (приложение 5 к ПП № 945-ПП, в редакции от 05.08.2026)

Способ расчёта выбирается пользователем; оба метода дают одно и то же постоянное число мест при эквивалентных исходных данных.

**Метод АГР / АСП — приложение 5, п. 2** (для архитектурно-градостроительных и архитектурно-строительных решений):

```
Nп = A × N1 + B × N2 + C × N3
A = 0,8   B = 1,2   C = 1,6   (мест на квартиру)
N1 — квартиры площадью до 70 кв.м
N2 — квартиры площадью от 70 до 100 кв.м включительно
N3 — квартиры площадью свыше 100 кв.м, а также индивидуальные жилые дома
     и блокированная застройка
```

**Метод градостроительного проектирования (ПЗ) — приложение 5, п. 1** (для проекта планировки территории):

```
Nп = S / (S1 × 2,1) × D
S   — общая площадь квартир, кв.м
S1  — площадь квартир на одного жителя (ПП № 2152-ПП, п. 1.4.2, табл. 1.4.1)
2,1 — средний размер домовладения, человек
D   = 0,8 — число мест постоянного размещения на одну квартиру
```

**Округление:** итоговое число мест округляется **в большую сторону по итогу**, а не по каждой группе (приложение 6, примечание 3). В таблице результатов по группам показываются расчётные доли без округления, округлённое значение — в строке «Итого».

**Вывод для экспертизы:** таблица расчёта (группа → количество → коэффициент → доля мест → пункт НД) + текстовое обоснование с реквизитами акта и указанием метода.

### 2.2 Допустимое отклонение от расчётного числа мест (п. 6.2.4.1–6.2.4.3)

| Группа мест | Допустимое отклонение | Пункт | Примечание |
|---|---|---|---|
| Постоянные, гостевая парковка, места остановки | ±10 % | п. 6.2.4.1 | отклонение более 10 % — решение ГЗК Москвы (п. 6.2.4.2) |
| Приобъектная парковка | ±30 % | п. 6.2.4.3 | округление результата — вверх |

Применение: `N = ⌈N_расч × k⌉`, `k = 1,0 / 0,9 / 1,1` (постоянные) и `1,0 / 0,7 / 1,3` (приобъектная). Значение по умолчанию — отклонение не применяется. Выбранное отклонение и предупреждение о ГЗК выводятся в блоке результатов и в обосновании.

**Важно:** коэффициент доступности рельсового каркаса к постоянным местам **не применяется** — в приложении 5 (в редакции от 05.08.2026) он отсутствует; используется только как К1 для приобъектной парковки (приложение 6).

### 2.3 Гостевая парковка (п. 6.2.3.2)

```
N_гост = ⌈0,10 × N_постоянные⌉   (10 % от числа постоянных мест)
```

Дополнительно проверяется минимум по СП 42.13330.2026, п. 8.117: не менее 30 машино-мест на 1000 жителей (или по НГП/РНГП/МНГП). При недостатке выводится предупреждение с указанием требуемого минимума.

### 2.4 Приобъектные машиноместа (приложение 6 к ПП № 945-ПП)

```
Nв = X / X2 × К1 × К2
X   — площадь (либо иная расчётная единица) объекта
X2  — расчётный показатель на одно парковочное место по виду разрешённого
      использования (приложение 1 к Нормативам)
К1  — коэффициент пешей доступности рельсового каркаса:
      менее 1200 м (15 мин. пешком) — 0,75; 1200–2200 м (до 30 мин.) — 0,9;
      более 2200 м — 1,0
К2  — уточняющий коэффициент деловой активности районов города Москвы
      (приложение 3 к Нормативам) — вводится пользователем
```

Итог округляется в большую сторону (примечание 3 к приложению 6). Построчно: `X / X2` по каждой функции; при нескольких сценариях использования принимается максимум.

### 2.5 Места для МГН (181-ФЗ ст. 15; СП 59.13330.2020 п. 5.2.1)

Два уровня, показываются раздельно и **в итоговое число мест не входят**:

```
# квота по закону
N_МГН = max(1, ⌈0,10 × N_общ⌉)

# специализированные места (6,0 × 3,6 м)
N ≤ 100   → max(1, ⌈0,05 × N⌉)
101–200   → 5 + ⌈0,03 × (N − 100)⌉
201–500   → 8 + ⌈0,02 × (N − 200)⌉
N ≥ 501   → 14 + ⌈0,01 × (N − 500)⌉
```

Дополнительно считаются специализированные места из гостевой (10 % от гостевых) и из приобъектной (10 % от приобъектных) парковки. Габариты: обычное место — не менее 5,3 × 2,5 м (приложение А к СП 113.13330.2023), специализированное — 6,0 × 3,6 м, вдоль проезжей части длина 6,8 м.

### 2.6 Места постоянного размещения для инвалидов (п. 6.2.3.7)

Из общего числа постоянных мест выделяются места постоянного размещения для инвалидов — 1 место на каждую квартиру для проживания инвалидов (по заданию на проектирование). В расчёте показываются отдельной строкой; **общее число постоянных мест не увеличивается**.

### 2.7 Предельно допустимая удалённость машиномест (п. 6.1.2.5)

| Вид мест | Нормативное расстояние |
|---|---|
| Постоянные | не далее 1200 м |
| Гостевая парковка | не далее 200 м |
| Приобъектная парковка | не далее 200 м |

Выводится справочно с проверкой расстояний по генплану.

### 2.8 Места с зарядной инфраструктурой

10 % от постоянных машиномест (округление вверх, не менее 1) — справочно, в итог не входят. Значение помечено как справочное: числовой нормы 10 % в СП 42.13330.2016 и СП 42.13330.2026 нет, подлежит уточнению по НГП/РНГП/МНГП региона. Инженерная инфраструктура (кабель-каналы, шинопроводы) — на 100 % машиномест.

### 2.9 Итоговая потребность и выгрузка блока

```
N_итог = N_постоянные + N_гостевые + N_приобъектные     (МГН справочно)
```

Выводится формула в текстовом виде, значение, список составляющих с пунктами НД, текстовое нормативное обоснование (4–6 абзацев) и таблица нормативных ссылок.

### 3.2 Режим «расчёт по ГОСТ Р 52941»

Исходные данные: поэтажная площадь квартир, высота этажа, общая площадь квартир на одного проживающего. При отличии от принятых в таблице система:

- выводит предупреждение с перечнем отклонений;
- требует указать принятое число лифтов (результат расчёта по ГОСТ Р 52941) и **не допускает значения меньше таблицы В.1**;
- формирует готовый текст обоснования для пояснительной записки (включается в выгрузки).

## Вкладка 5: ТКО

```
Vгод    = Sкв × n                                  [м³/год]
Vсут    = Vгод / 365                               [м³/сут]
Vнакопл = Vсут × T × Kн                            [м³]
Vпол    = Vконт × Kз                               [м³]
Nконт   = ⌈Vнакопл / Vпол⌉                         [шт]
Sосн    = (длина × ширина) / 1e6                   [м²]
S1      = ((длина + зазор) × (ширина + зазор)) / 1e6   [м²]
Sобщ    = Nконт × S1                               [м²]
Sпом    = (Sобщ / nпом) × Kпр                      [м²]
Sсум    = Sпом × nпом                              [м²]
Mгод    = Vгод × ρ                                 [т/год]
```

Поля: площадь квартир; норматив накопления n (только чтение, из базы); сезонный коэффициент (только чтение); плотность ρ (только чтение, справочно); период вывоза T; объём, длина и ширина контейнера; Kн, Kз, Kпр (только чтение); количество контейнерных помещений; зазор между контейнерами. Разбивка по фракциям — справочная, доли задаются пользователем.

Нормативные ссылки: СанПиН 2.1.3684-21 (п. 3 — размещение мест накопления, зазор 0,35 м; п. 11 — срок временного накопления: до 1 сут при +5 °C и выше, до 3 сут при +4 °C и ниже); СП 42.13330.2026, приложение Ж «Количество коммунальных отходов»; ФЗ № 89-ФЗ; региональные акты о нормативах накопления.

## Нормативная база и её актуальность

1. **Единый источник правды — `app/data/norms.json`.** Разделы: `meta`, `regions` (86 субъектов РФ + федеральная база; для Москвы — детальные значения), `legalActs` (реестр актов со статусами для проверки актуальности), `parking`, `elevators`, `tko`, `social`. Формулы реализованы в коде, значения и коэффициенты — в JSON. У каждого правила есть `refPoint`.
2. **Региональные приоритеты:** РНГП/МНГП субъекта РФ (ст. 29.2 ГрК РФ) → федеральный ориентир СП 42.13330.2026. Контроль федерального минимума — Приказ Минстроя РФ № 250/пр от 23.04.2025.
3. **Оффлайн-режим:** в `app/index.html` встроена копия норм для работы по `file://`. Копия **не редактируется вручную** — генерируется скриптом `node tools/build-embedded-norms.mjs` (проверка актуальности — `--check`).
4. **Второй движок:** `python/parking_calc.py` — независимая реализация расчёта машиномест по ПП № 945-ПП поверх той же `norms.json`; контрольные примеры JS и Python дают совпадающие числа.
5. **Журнал проверки норм** (кнопка «Проверить на актуальность норм») выгружается в CSV и включается в итоговый документ и раздел для пояснительной записки.
6. **Процедура сопровождения базы** оформлена навыком `.opencode/skills/norm-audit-calc`: верификация текстов НД по первоисточникам, headless-прогон расчётов, правка `norms.json` и кода, проверка в браузере и обязательное **сохранение результата** в `reports/YYYY-MM-DD_<тема>.md`. Отчёт самодостаточен: предмет проверки, подтверждённая нормативная база со ссылками на пункты, расхождения и как устранены, контрольные прогоны, что не подтверждено, изменённые файлы, следующие шаги.

## Проверка расчётов и защита от ошибок

1. **Единая база исходных данных:** все вкладки используют данные из вкладки 1 — это исключает расхождения.
2. **Автоматическая подстановка нормативов:** при выборе региона система подтягивает применимые РНГП, ПП и приказы.
3. **Контроль федерального минимума:** если региональный норматив ниже федерального (по Приказу Минстроя № 250/пр), система выдаёт предупреждение и применяет федеральное значение.
4. **Валидация реалистичности:** проверка плотности, соотношений площадей и численности.
5. **Ссылки на нормативы:** в каждом расчёте явно указаны реквизиты акта (код, пункт, редакция) — в таблицах, текстовых обоснованиях и выгрузках.
6. **Допущения:** отдельный блок с описанием, какие коэффициенты применены и почему (выгружается в Word и HTML).
7. **Контроль округления:** округление вверх выполняется по итогу, а не по строкам — там, где это предписано НД (приложение 6, примечание 3).
8. **Проверка минимумов:** гостевая парковка — не менее 30 ММ на 1000 жит. (СП 42.13330.2026, п. 8.117); лифты — не менее таблицы В.1 (СП 54.13330.2022, прил. В, примечание 3); площади квартир — не менее таблицы 5.1 (п. 5.2).
