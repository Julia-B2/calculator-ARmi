# Дизайн-гайд: сайт-визитка «Внедрение ИИ-агентов»

Версия: v1
Дата: 2026-10-19
Направление: футуристичный/технологичный стиль с ИИ-метафорами, неоновыми акцентами и умеренной анимацией
Акцентный цвет: `#2456E6`
Статус: на согласовании → после утверждения собирается HTML-макет

Дополняет и уточняет ТЗ (`2026-10-19_Визитка_ТЗ-для-ИИ-агента_v1.md`). В случае расхождений приоритет — у этого гайда по визуальной части, у ТЗ — по структуре и функционалу.

## 1. Концепция

Тёмный «цифровой» интерфейс: глубокий тёмно-синий фон, на нём — узлы и связи нейросети, градиентные акценты синий → циан, неоновое свечение только у ключевых элементов. Сайт выглядит технологично и живо за счёт продуманной анимации появления, но остаётся спокойным для чтения: один анимированный фоновый эффект на секцию, никакого «цифрового шума».

Правило верхнего уровня: **технологичность — в деталях (градиенты, свечение, моно-шрифт, анимация появления), а не в заливке всего экрана эффектами.**

### 2.3 Ограничения по цвету

- В пределах одной секции — не более **двух** элементов со свечением (glow).
- Градиент `синий → циан` — только на CTA, одной ключевой надписи в заголовке и активных узлах графика. Не раскрашивать им фоны карточек целиком.
- Красный/жёлтый — только для статусов (ошибка, предупреждение), не как декор.
- Любой текст на фоне `#070B14`/`#0D1424` — контраст ≥ 4.5:1 (эти роли уже проверены: `#EEF2F8` и `#9AA6BC` проходят, `#66748F` — только для крупного/декоративного текста).

## 5. Визуальный язык: ИИ-метафоры

| Метафора | Реализация | Где |
|---|---|---|
| Узлы нейросети | Canvas: 40–60 точек, соединённых тонкими линиями `rgba(77,139,255,0.25)`, медленное дрейфование | фон Hero |
| Поток данных / код | Терминальная карточка: имитация консоли агента с печатающимся текстом (однократно при загрузке) | визуал Hero |
| Граф решения задачи | Интерактивная цепочка-граф: линия «прорисовывается» при скролле, узлы загораются последовательно | секция «Доверие» |
| Градиент-акценты | Синий → циан только по правилам п. 2.2 | CTA, ключевые слова, узлы графа |
| Неоновые иконки | Линейные SVG-иконки, `stroke-width: 1.5`, при hover — цвет `#4D8BFF` + лёгкое свечение | карточки пользы, контакты |
| Моно-подписи | Код-подобные подписи: `// advantages`, `01 / 05`, метрики | лейблы секций, цифры |

Иконки — inline SVG единого стиля (одна сетка 24×24, скруглённые концы), без наборов-иконок «из интернета» с разным стилем.

## 6. Дизайн по секциям

### 6.1 Hero (`#hero`)

- **Фон:** canvas-нейросеть (узлы + связи, дрейф) + координатная сетка + 1 градиентное пятно. Скорость дрейфа — медленная, линии тонкие, прозрачность ≤ 0.25.
- **Сетка:** 2 колонки (на мобиле — 1): слева текст, справа визуал.
- **Слева:**
  - **фото-блок владельца (верхний элемент):** **квадратное** фото 64×64px (на мобиле 56×56px) из `assets/photo.png`, `object-fit: cover`, радиус 12px, ободок — градиентная рамка 2px `#2456E6 → #22D3EE` с мягким свечением `rgba(36,86,230,0.45)`; справа от фото подпись **«Баранова Юлия»** — Inter 600, `1.05rem`, `#EEF2F8`; между фото и подписью допустима тонкая вертикальная линия `rgba(77,139,255,0.25)`. Появляется в каскаде первым (задержка 0). Исходник фото владельца — `Визитка\мое фото.png`: при сборке макета файл **копируется** в `assets/photo.png`, оригинал не переименовывать и не перемещать;
  - моно-лейбл `// внедрение ИИ-агентов в бизнес` цветом `#4D8BFF`;
  - H1, одно ключевое слово — градиентом;
  - подзаголовок `#9AA6BC`;
  - CTA «Обсудить задачу» — градиентная кнопка со свечением; вторичная кнопка — «призрачная» (рамка `rgba(77,139,255,0.3)`, без заливки);
  - 3 метрики строкой: моно-цифры + подпись, разделены тонкой вертикальной линией.
- **Справа — терминальная карточка:**
  - окно стиля терминала: три точки-управления сверху, заголовок моно-шрифтом `agent.run()`;
  - внутри — печатающаяся последовательность (однократно, ~2 с, с курсором-блоком):
    ```
    > задача: заявки вручную
    > агент: подключён к каналу
    > ручные часы: 32ч/мес → 0ч
    > статус: результат подтверждён ✓
    ```
  - строка с эффектом: «ноль ручных часов» — цветом `#34D399`.
- Запрещено: стоковые роботы/мозги, 3D-картинки, видео-фон.

### 6.2 Польза (`#benefits`)

- Лейбл `// 02 — что меняется`, H2 (одно слово — градиент).
- Сетка карточек 3×2 (планшет 2, мобайл 1).
- **Карточка:** поверхность `#0D1424`, рамка-градиент появляется только на hover; сверху линейная иконка, затем `Было` (приглушённый текст `#66748F`, зачёркнутая или в рамке «до») → стрелка `→` цветом `#22D3EE` → `Стало` (`#EEF2F8`); внизу метрика результата моно-шрифтом, градиентная.
- **Hover (по требованию владельца):** карточка поднимается `translateY(-4px)`, фон светлеет до `#121B30`, иконка окрашивается в `#4D8BFF` со свечением, по периметру проявляется градиентная рамка. Переходы `180–220ms`, `ease-out`.
- На тач-устройствах hover-эффекты не обязательны, карточки остаются в базовом, но уже нарядном виде.

### 6.3 Доверие (`#trust`)

Четыре подблока:

1. **Интерактивный график «Как агент решает задачу»** (ключевой элемент по запросу владельца):
   - SVG-цепочка 5 узлов: `Цель → Диагностика → Пилот → Внедрение → Результат`.
   - При попадании в вьюпорт: соединительная линия **прорисовывается** слева направо (`stroke-dashoffset`, ~1.2 с), затем узлы загораются последовательно с задержкой ~250 мс — «алгоритм выполняется».
   - Узел: круг 12px, базовый цвет `#4D8BFF` с мягким свечением; активный — заливка градиентом.
   - Под каждым узлом: моно-подпись + срок (`неделя`, `2–4 недели`…).
   - **Интерактив:** при наведении/тапе на узел — всплывающая карточка (tooltip) с 1–2 строками описания; активный узел увеличивает свечение.
   - На мобиле: вертикальная цепочка сверху вниз с тем же эффектом прорисовки.
2. **Кейсы:** карточки-«листы» с углой засечкой; внутри структура `Задача → Решение → Результат`; результат — крупной моно-метрикой. При hover — подсветка рамки (как в п. 6.2, но мягче).
3. **Обо мне:** фото со скруглением 14px, тонкая градиентная подложка под ним (имитация «подсветки»); текст справа.
4. **Гарантии:** строка бейджей — «пилюль» с иконкой (NDA, поэтапная оплата, поддержка); полупрозрачная поверхность `rgba(13,20,36,0.7)`, рамка как в п. 4.

### 6.4 Форма (`#contact-form`)

- Сетка 2 колонки: слева — 3 аргумента «что произойдёт после отправки» (нумерованные, моно-цифры `01/02/03`), справа — карточка формы.
- Карточка формы: поверхность `#0D1424`, рамка `rgba(77,139,255,0.16)`, **hover/focus карточки** — мягкое внешнее свечение `rgba(36,86,230,0.25)`.
- Инпуты: фон `#070B14`, текст `#EEF2F8`, плейсхолдер `#66748F`; **focus** — рамка `#2456E6` + свечение `0 0 0 3px rgba(36,86,230,0.25)`.
- Ошибка — рамка/текст `#F87171` + сообщение под полем.
- Кнопка — градиентная со свечением; состояние «Отправляю…» — disabled + тонкий прогресс-индикатор; успех — блок с галочкой `#34D399` (лёгкая анимация отрисовки галочки).
- Чекбокс согласия — кастомный, при включении — галочка градиентом.

### 6.5 Контакты и футер (`#contacts`)

- Секция чуть «светлее» базы: `#0D1424`, верхний разделитель — тонкая градиентная линия.
- Крупные ссылки-контакты списком: иконка + текст; **hover** — текст `#4D8BFF`, иконка со свечением, сдвиг `translateX(4px)`.
- Акцентная кнопка «Написать в Telegram».
- Нижняя строка (футер): копирайт, политика конфиденциальности, переключатель языка — моно, `#66748F`.

## 7. Анимации

| # | Эффект | Реализация | Триггер |
|---|---|---|---|
| 1 | Появление секций «работой алгоритма» | `opacity 0→1` + `translateY(16px→0)`, 450–550ms, `cubic-bezier(0.22, 1, 0.36, 1)`, у элементов внутри — каскадная задержка **80 мс** на элемент (sequential reveal) | `IntersectionObserver`, однократно |
| 2 | Прорисовка линии графа | SVG `stroke-dasharray/offset`, 1.2 с | при въезде графа во вьюпорт |
| 3 | Последовательное зажигание узлов | `scale(0.8→1)` + увеличение glow, задержка 250 мс между узлами | после п. 2 |
| 4 | Печать в терминале | посимвольный вывод ~30–40 мс/символ, однократно, курсор-блок мигает | загрузка страницы |
| 5 | Дрейф фоновых пятен | `transform: translate` по ключевым кадрам, цикл 20–30 с | всегда |
| 6 | Canvas-нейросеть | медленный дрейф узлов, линии перерисовываются | всегда, но **пауза** при `document.hidden` и при `prefers-reduced-motion` |
| 7 | Hover карточек/кнопок/ссылок | `transform`, `box-shadow`, `border-color`; 180–220ms `ease-out` | наведение |

**Жёсткие правила:**
- Анимируются только `transform` и `opacity` (+ `stroke-dashoffset` для SVG) — никакой анимации `width/height/top/left`, никакого layout thrashing.
- Ни одного эффекта, мигающего быстрее 2 раз в секунду; никакого стробирования, мерцания текста, авто-скролла, параллакса-«качелей».
- Scroll-jacking запрещён: только нативный скролл.
- Одновременно на экране — не более 2 фоновых анимаций.
- **`prefers-reduced-motion: reduce`** — отключает п. 1–6 (остаётся статичная отрисовка в конечном состоянии), hover-переходы — мгновенные.

## 8. Интерактив (сводка)

1. Карточки пользы и кейсов — hover-подъём с градиентной рамкой (п. 6.2).
2. Граф «Цель → Результат» — прорисовка при скролле, тап/наведение на узлы с подсказками (п. 6.3).
3. Терминал в Hero — печать при загрузке (п. 6.1).
4. Кнопки и ссылки — glow-переходы.
5. Форма — focus-свечение, анимированная отправка/успех (п. 6.4).
6. Переключатель RU/EN — активная кнопка с градиентной подчёркивающей линией.

Все интерактивы работают с клавиатуры (`Tab`, `Enter/Space`), у узлов графа — фокусируемые элементы с `aria-label`.

## 9. Правила «антишума» (чек-лист дизайнера)

- [ ] Не более **одного** анимированного фона на секцию.
- [ ] Не более **двух** glow-элементов в одной секции.
- [ ] Градиентным текстом — максимум одно слово в заголовке.
- [ ] Всё основное — статично и читается сразу; анимация усиливает, а не заменяет контент.
- [ ] Через 3 секунды пребывания на секции экран полностью статичен (кроме очень медленного дрейфа фона).
- [ ] Контраст текста ≥ 4.5:1 в любом состоянии (в т.ч. hover).
- [ ] Отключённый JS и `reduced-motion` дают спокойную, цельную страницу без пустых мест.
