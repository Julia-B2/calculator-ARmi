# Somniumsol — превью нового сайта

Статическое превью нового фирменного сайта и магазина. Это не готовая WooCommerce-тема, а дизайн-прототип с рабочей витриной, корзиной, подпиской, подарочными наборами и демонстрационным оформлением заказа.

## Что внутри

| Файл                    | Назначение                                                                           |
| ----------------------- | ------------------------------------------------------------------------------------ |
| `index.html`            | Главная: манифест, каталог, директории, подписка, процесс, наборы, квиз, журнал, FAQ |
| `catalog.html`          | Каталог трёх сортов, только формат 1 кг, и подписка                                  |
| `product.html?id=epico` | Карточка товара; `sidamo`, `mariposa` — другие вкусы                                 |
| `subscription.html`     | Конфигуратор подписки, тариф «Полный круг» (1 кг)                                    |
| `gifts.html`            | Подарочные наборы и корпоративный блок                                               |
| `checkout.html`         | Демонстрационное оформление заказа                                                   |
| `about.html`            | История бренда, ценности, таймлайн                                                   |
| `delivery.html`         | Доставка, оплата, возврат                                                            |
| `legal.html`            | Юридические тексты-заготовки                                                         |
| `404.html`              | Страница ошибки                                                                      |
| `presentation.html`     | Презентация проекта для клиента                                                      |

## Как открыть

1. Откройте `preview/index.html` в Chrome, Safari или Firefox.
2. Если браузер ограничивает локальные файлы, запустите любой статический сервер из папки `preview`:
   - VS Code → расширение Live Server → `index.html` → Open with Live Server;
   - или `npx serve .` / `python -m http.server 4173`.
3. Все страницы связаны между собой, поэтому навигацию можно проверять целиком.

## Что работает в превью

- Каталог, фильтры, карточки товара, разовая покупка или подписка; формат один — 1 кг, кофе только в зёрнах (выбор помола убран).
- Корзина в выдвижной панели: количество, удаление, сумма, порог бесплатной доставки. При 5+ пачках вместо прогресса появляется кнопка «Бесплатная доставка по Москве» (ведёт в чекаут); в чекауте над списком доставок появляется кнопка «Включить бесплатную доставку по Москве» — она выбирает курьера, а цена курьера меняется на «Бесплатно».
- Конфигуратор подписки с пересчётом цены и скидкой 10%.
- Подарочные наборы и добавление в корзину.
- Квиз подбора кофе.
- Поиск по сортам.
- Оформление заказа: контакты, доставка, оплата, промокоды, экран успеха.
- Данные корзины и заказов сохраняются в `localStorage` браузера.

### Демо-промокоды

| Код | Эффект |
|---|---|
| `SOL10` | −10% на сумму товаров |
| `SOMNIUM` | Бесплатная доставка |

### Сброс демо-данных

В консоли браузера:

```js
localStorage.removeItem('somniumsol_cart_v1');
localStorage.removeItem('somniumsol_orders_v1');
location.reload();
```

## Что демонстрационное

- **Оплата.** Реальные ЮKassa и CloudPayments не подключены: нет merchant-аккаунтов, ключей и боевого домена. На экране оплаты работает только демонстрационный сценарий, деньги не списываются.
- **Заказ.** Заказ сохраняется в браузере и передаётся менеджеру через WhatsApp/Telegram. Серверной части, базы заказов и писем нет.
- **Подписка.** Расписание, пауза и отмена показаны как сценарий; регулярных списаний нет.
- **Доставка.** Стоимость и сроки зашиты в демо-данные; API СДЭК и Почты России не подключены.
- **Наличие.** Остатки не учитываются.
- **Контент.** Описания, дегустационные ноты, даты и юридические тексты — заготовки, требуют проверки владельцем.

## Где менять данные

Единый источник цен, сортов, наборов, тарифов и промокодов:

`preview/assets/js/data.js`

Основные блоки:

- `settings` — контакты, доставка, порог бесплатной доставки;
- `products` — сорта, цены за 1 кг, цены подписки, галереи;
- `formats` — подписка;
- `gifts` — подарочные наборы;
- `plans` — тарифы подписки;
- `promos` — промокоды.

После изменения цен проверьте: карточку товара, каталог, конфигуратор подписки, корзину, checkout и экран успеха.

## Изображения

В превью использованы:

- фотографии с действующего сайта Somniumsol;
- сгенерированные изображения `gen-hero.jpg`, `gen-pour.jpg`, `gen-cherries.jpg`, `gen-gift.jpg` (SDXL, локальная генерация);
- фирменные SVG-иллюстрации подарочных наборов и иконки;
- оригинальный логотип `assets/img/logo-somniumsol.png` и `logo-somniumsol-light.png` — надпись бренда, её нельзя перенабирать и перерисовывать.

Для запуска нужна собственная фотосъёмка: упаковка на цветном фоне, руки, чашка, зерно, детали. Сгенерированные кадры — временные заглушки, их нельзя выдавать за реальный продукт. Проверьте права на все фотографии с текущего сайта.

## Технические заметки

- Вёрстка адаптивная: проверены 360, 390, 768, 1024, 1280 и 1440 px.
- Шрифты Cormorant Garamond и Manrope лежат локально в `assets/fonts`, внешние CDN не нужны.
- Анимации отключаются при `prefers-reduced-motion`.
- Формы помечены `aria-*`, есть skip-link и видимый фокус.
- `body::before` добавляет плёночное зерно поверх страницы; на слабых устройствах его можно отключить.
- Превью не содержит серверного кода и не требует сборки.
