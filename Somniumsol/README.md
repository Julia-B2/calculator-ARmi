Комплект для перезапуска somniumsol.ru: статическое превью нового сайта, документация по бренду, ценам, переезду и запуску.

## Быстрый старт

Откройте `preview/index.html` в браузере. Если нужен локальный сервер:

```bash
cd preview
npx serve .
# или
python -m http.server 4173
```

Подробности — в `preview/README.md`.

## Что уже работает

- Каталог Epico, Sidamo, Mariposa; **только пачки 1 кг**.
- Корзина, количество, удаление, прогресс до бесплатной доставки от 5 пачек.
- Подписка «Солнцестояние» — один тариф «Полный круг», 1 кг, скидка 10%.
- Подарочные наборы из 1 кг-пачек: сборка 2–3 рабочих дня, под заказ.
- Промокоды `SOL10` и `SOMNIUM`.
- Демо-checkout с экраном успеха и сохранением заказа в браузере.
- Поиск, квиз, FAQ, адаптивная вёрстка.
- Смоук-проверки в браузере после обновления данных: каталог, карточка, подписка, наборы, корзина, оформление.

## Что демонстрационное

Оплата, доставка, подписка и заказы **не подключены к реальным сервисам**. Деньги не списываются, заказы живут в `localStorage`, API СДЭК, Почты России, ЮKassa и CloudPayments отсутствуют. Это честно указано в интерфейсе и документации.

## Ключевые решения по контенту

- **Логотип** — оригинальная надпись Somniumsol из `assets/img/logo-somniumsol.png` (тёмная) и `logo-somniumsol-light.png` (кремовая). Не перенабирать и не перерисовывать.
- **Контакты:** `AJ.somnium@yandex.ru`, +7 (926) 112-27-17, Москва, Переведеновский пер., 18, стр. 15.
- **Наборы:** сборка 2–3 рабочих дня, этикетки под заказ не печатаем, срок уточняем при подтверждении.
- **Тексты про обжарку:** не пишем, где и в какие дни обжариваем и какой свежести отправляем — только вкус, происхождение, формат и условия доставки.

## Что дальше

1. Утвердить дизайн и контент.
2. Получить доступы: домен, хостинг, ЮKassa/CloudPayments, СДЭК/Почта.
3. Собрать WooCommerce на staging по `docs/04-woocommerce-migration.md`.
4. Пройти `docs/05-launch-checklist.md`.
5. Переключить домен по `docs/03-replace-or-republish.md`.

## Ограничения

- Реальная оплата и фискализация невозможны без merchant-аккаунтов и ключей.
- Реальная доставка невозможна без договоров и API СДЭК/Почты.
- Автоплатежи подписки требуют поддержки со стороны платёжного провайдера.
- AI-изображения — временные заглушки; для запуска нужна съёмка реальной упаковки.
- Юридические тексты — заготовки, требуют проверки юристом и бухгалтером.
