# Somniumsol — превью

Статический прототип нового сайта и магазина. Без сборки, сервера и базы данных.

## Быстрый старт

Откройте `index.html` в браузере. Если локальные файлы ограничены, запустите статический сервер из этой папки:

```bash
npx serve .
# или
python -m http.server 4173
```

Затем откройте `http://localhost:4173`.

## Страницы

| Файл | Что смотреть |
|---|---|
| `index.html` | Главная: манифест, каталог, подписка, наборы, квиз, FAQ |
| `catalog.html` | Каталог: три сорта, только формат 1 кг |
| `product.html?id=epico` | Карточка товара; также `sidamo`, `mariposa` |
| `subscription.html` | Конфигуратор подписки |
| `gifts.html` | Подарочные наборы |
| `checkout.html` | Демонстрационное оформление |
| `about.html` | О бренде |
| `delivery.html` | Доставка и оплата |
| `legal.html` | Юридические заготовки |
| `404.html` | Ошибка |
| `presentation.html` | Презентация проекта для клиента |

## Что работает

- Каталог в формате 1 кг, подписка, наборы.
- Корзина в drawer, количество, удаление, прогресс до бесплатной доставки.
- Промокоды `SOL10` (−10%) и `SOMNIUM` (бесплатная доставка).
- Демо-checkout с сохранением заказа в `localStorage`.
- Поиск, квиз, FAQ, адаптивная вёрстка.

## Что демонстрационное

Оплата, доставка, подписка, остатки и заказы — **не настоящие**. Деньги не списываются, заказы живут только в браузере, API СДЭК/Почты/ЮKassa/CloudPayments не подключены. Подробности — в `../docs/00-preview-guide.md`.

## Данные

Единый источник цен и контента: `assets/js/data.js`.

Сброс демо-данных:

```js
localStorage.removeItem('somniumsol_cart_v1');
localStorage.removeItem('somniumsol_orders_v1');
location.reload();
```
